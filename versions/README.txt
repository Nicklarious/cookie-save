Cookie Save versions

macOS
  Open Cookie Save.app.

Chrome
  Open Cookie Save.html. Double-click it, or drag it onto Chrome.

Windows
  Double-click Cookie Save.bat. It opens Cookie Save.html in the browser.
  This folder is the browser editor. There is no separate Windows program.

Linux
  Run ./Cookie Save.sh, or open Cookie Save.html in Chrome.
  This folder is the browser editor. There is no separate Linux program.

The Chrome, Windows, and Linux folders each hold the same editor.
They read and write a Cookie Clicker 2.058 export the same way as the Mac app.
Each of those folders can be moved on its own. The html file uses the scripts beside it.

Cookie Save is an unofficial fan tool. It is not affiliated with Orteil or DashNet.
Cookie Clicker is their game.
