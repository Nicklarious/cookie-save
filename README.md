# Cookie Save

Unofficial fan tool for editing a Cookie Clicker 2.058 save export.

Cookie Clicker is a game by Orteil and DashNet. Cookie Save is not affiliated with them. This repository does not include the game, and it does not include a personal bakery save.

## Mac app

`versions/macOS/Cookie Save.app` is the built app. Open that.

The source in this folder builds the same app. On this Mac, `build.sh` compiles it and copies it to the Desktop Projects folder.

## Browser

`versions/Chrome`, `versions/Windows`, and `versions/Linux` each hold the same editor.

- Chrome: open `Cookie Save.html`.
- Windows: double-click `Cookie Save.bat`. That folder is the browser editor. There is no separate Windows program.
- Linux: run `./Cookie Save.sh`, or open `Cookie Save.html`. There is no separate Linux program.

Each of those folders can be moved on its own. The page uses the scripts beside it.
